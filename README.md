# Digital Shadow

Digital Shadow is a cybersecurity OSINT tool that analyzes publicly available information related to an email address or username. It helps users understand their digital footprint and potential security risks.

The application scans for exposure indicators, calculates a risk score, and visualizes relationships between discovered data using an interactive graph interface.

## Features
- Email or username scanning
- Digital footprint analysis
- Risk score calculation
- Interactive entity graph
- Cybersecurity recommendations

## Tech Stack
- Python
- Flask
- HTML / CSS / JavaScript
- Cytoscape.js

## Purpose
This project was developed as part of a cybersecurity hackathon to demonstrate how publicly available information can be analyzed to improve online security awareness.

⚠️ This tool uses only publicly available data and is intended for educational purposes.
